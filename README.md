# Equation Solver - Web版

元のTkinterベースのデスクトップアプリケーションをWebアプリケーションに変換しました。

## 機能

- **方程式入力**: 複数の方程式を入力可能
- **変数指定**: 解く変数を指定、または自動検出
- **記号対応表**: 数学記号の入力方法を確認
- **解の表示**: LaTeX形式で美しく表示
- **レスポンシブデザイン**: PC・スマートフォン対応

## 必要な環境

- Python 3.7以上
- Flask
- SymPy
- Matplotlib
- NumPy

## インストール

1. 必要なパッケージをインストール:
```bash
pip install -r requirements.txt
```

## 実行方法

1. アプリケーションを起動:
```bash
python app.py
```

2. ブラウザで以下のURLにアクセス:
```
http://127.0.0.1:5000
```

## 使用方法

### 1. 方程式の入力
- 「追加」ボタンで方程式入力欄を追加
- 例: `x**2 + 2*x + 1 = 0`
- 「削除」ボタンで不要な方程式を削除

### 2. 変数の指定
- 「追加」ボタンで変数入力欄を追加
- 「自動追加」ボタンで方程式から自動検出
- 例: `x`, `y`, `z`

### 3. 解を求める
- 「解を求める」ボタンをクリック
- または `Ctrl + Enter` で実行

### 4. その他の機能
- **記号対応表**: 数学記号の入力方法を確認
- **AC**: 全ての入力をクリア
- **ESC**: モーダルを閉じる

## 対応する記号・関数

| 記号 | 入力方法 | 例 |
|------|---------|-------|
| + | + | x + 2 |
| - | - | x - 3 |
| * | * | 2 * x |
| / | / | x / 5 |
| ^ | ** | x**2 |
| = | = | x + 2 = 5 |
| √ | sqrt(x) | sqrt(x) |
| π | pi | pi * r**2 |
| e | E | E**x |
| sin | sin(x) | sin(x) |
| cos | cos(x) | cos(x) |
| log | log(x) | log(x) |
| log10 | log(x, 10) | log(x, 10) |

## 例: 二次方程式を解く

1. 方程式入力欄に `x**2 - 5*x + 6 = 0` と入力
2. 変数入力欄に `x` と入力（または自動追加）
3. 「解を求める」ボタンをクリック
4. 解: `x = 2`, `x = 3` が表示される

## 例: 連立方程式を解く

1. 方程式1: `2*x + 3*y = 7`
2. 方程式2: `x - y = 1`
3. 変数: `x`, `y`（または自動追加）
4. 解: `x = 2`, `y = 1` が表示される

## 注意事項

- 係数と変数の間には `*` を明示的に書くことを推奨（例: `2*x`）
- 自動補完機能もありますが、明示的な方が確実です
- 複雑な方程式では解が見つからない場合があります

## Androidスマートフォンでの使用方法

### 1. ブラウザでアクセス

1. **Chrome**、**Firefox**、**Edge**などのモダンブラウザを開く
2. 以下のURLにアクセス:
   ```
   http://[PCのIPアドレス]:5000
   ```
   例: `http://192.168.0.21:5000`

### 2. PWA（アプリ）としてインストール

#### Chrome の場合:
1. ブラウザでサイトにアクセス
2. 右上のメニュー（⋮）をタップ
3. 「ホーム画面に追加」をタップ
4. 「インストール」をタップ

#### 自動インストールプロンプト:
- 初回アクセス時に「アプリをインストール」ボタンが表示される場合があります
- タップするとホーム画面にアプリアイコンが追加されます

### 3. モバイル最適化機能

✅ **タッチ操作対応**
- 大きなボタンサイズ（44px以上）
- タッチしやすいインターフェース
- スワイプジェスチャー対応

✅ **画面サイズ対応**
- レスポンシブデザイン
- 縦向き表示最適化
- 小さな画面での使いやすさ

✅ **入力支援**
- 自動補完・自動修正の無効化
- ズーム防止機能
- バーチャルキーボード対応

✅ **オフライン機能**
- Service Worker による基本的なオフライン対応
- 一度アクセスすれば、ネットワークなしでも基本機能が使用可能

### 4. スマートフォン固有の操作方法

#### 方程式の入力:
- **タップ**: 入力欄をタップして数式を入力
- **削除**: 各行の「削除」ボタンをタップ

#### 記号対応表:
- **表示**: 「記号対応表」ボタンをタップ
- **閉じる**: ×ボタンをタップ、または上方向にスワイプ

#### その他:
- **全クリア**: 「AC」ボタンをタップ
- **自動検出**: 「自動追加」ボタンをタップ

### 5. 推奨環境

- **Android 7.0以上**
- **Chrome 90以上** または **Firefox 90以上**
- **画面サイズ**: 5インチ以上推奨
- **ネットワーク**: Wi-Fi または 4G/5G

### 6. トラブルシューティング

#### アクセスできない場合:
1. PCとスマートフォンが同じWi-Fiネットワークに接続されているか確認
2. PCのファイアウォール設定を確認
3. ブラウザのキャッシュをクリア

#### 動作が重い場合:
1. ブラウザのタブを閉じて再度アクセス
2. スマートフォンを再起動
3. 他のアプリを終了してメモリを開放

#### 数式が表示されない場合:
1. ネットワーク接続を確認（MathJaxの読み込みが必要）
2. ブラウザでJavaScriptが有効になっているか確認
